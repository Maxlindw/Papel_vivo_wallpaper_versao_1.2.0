# Papel Vivo 2.0.1
## Your desktop, alive.
Local video and image wallpaper player for 64-bit Windows 10/11. No embedded browser, service or automatic startup. Your original wallpaper is not overwritten.

### Get started
1. Install and open Papel Vivo. Nothing starts playing automatically.
2. Choose a local video or image with **Choose media**.
3. Use **Test preview** or **Apply to desktop**. Applying another item automatically replaces the previous one after preparation succeeds.
4. Open **Gallery** to apply, rename or remove entries. **Ctrl+Z** undoes, **Ctrl+Y** redoes.
5. **Restore original** restores the desktop without closing. **Stop and exit** terminates the app and its helpers. Closing an active wallpaper with X asks for confirmation first.

**Language: PT / EN** changes the interface and saves the preference. No restart needed.

### Included
Persistent gallery, real thumbnails, automatic video optimization, live CPU/RAM readings, timed character notices, offline background removal with Python/rembg and a local model, FFmpeg/ffprobe and libmpv. Documentation and application sources are included in **Sources**. See **docs/Manual-EN.md** and **THIRD-PARTY-NOTICES.md**.

Setup is unsigned. Windows may show an unknown-publisher warning. Verify the download source and checksum. Do not disable protection to execute a file detected as malicious.
